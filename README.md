# ML-Based Smart Health Monitoring System

## Project Overview

The ML-Based Smart Health Monitoring System is a web-based application developed using Python and Flask. This project is designed to monitor health-related data and provide smart analysis using Machine Learning concepts. The system helps users manage and analyze health information in an easy and efficient way.

## Features

* User-friendly interface
* Health data analysis
* Machine Learning based prediction system
* Data visualization and monitoring
* Secure data handling
* Responsive web design

## Technologies Used

* Python
* Flask
* HTML
* CSS
* Bootstrap
* Machine Learning
* SQLite Database

## Purpose of the Project

The main purpose of this project is to learn how Machine Learning can be integrated with web development for smart healthcare solutions. This project also improves practical knowledge of Python, Flask, database management, and frontend integration.

## Project Structure

* Backend developed using Flask
* Frontend designed with HTML, CSS, and Bootstrap
* Database used for storing health records
* Machine Learning model used for prediction and analysis

## How to Run the Project

1. Clone the repository
2. Open the project folder
3. Install required libraries
4. Run the Flask application

```bash
pip install -r requirements.txt
python app.py
```
